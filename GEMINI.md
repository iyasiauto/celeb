# Gemini / Antigravity: read AGENTS.md first

This folder is a video-making kit. When the user wants a video (or says "video banao", "start", "make a video"),
follow **AGENTS.md** exactly: ask the 5 questions in one message, then run `make_video.py`, preferably as the
editor yourself (`--until shotlist`, write the shot list, `--resume plan`). The workflow `/make-video` (.agent/workflows) does the same.
Docs: kit_docs/START_HERE.md (user guide), kit_docs/TEMPLATES.md, kit_docs/DATA_SOURCES.md, docu/VISUAL_SYNC_GUIDE.md.
Never commit or print API keys (api_keys/keys.env is git-ignored).
