# Editing template: Documentary

This folder is an editing template. When it sits inside a project/niche folder, every video you plan, edit, render,
review or give feedback on in that project follows the editing style in `EDITING-STYLE.md` in this folder (and the look of `reference.jpg`, if present).

- Read EDITING-STYLE.md fully before any editing work in this project.
- Read EDIT-PLAYBOOK.md too: it decides, clip by clip, the cut, transition, effect and grade. Plan every video as an EDL first
  (section 10 prompt), then edit from the EDL.
- Look at each clip (frames) before deciding — the rules in section 3 depend on what the clip shows.
- The niche decides the CONTENT (topic, script, facts, footage subjects); this template decides the EDITING (cuts, pacing, captions, graphics, colours, fonts, sound).
- If the project already has another editing template folder, ask the user which one wins.
- Use whatever tools the project has; if a value here can't be reproduced exactly, get as close as possible and say what differs.
- Before calling a video done, go through the checklist at the end of EDITING-STYLE.md.
- Never change this template folder unless the user asks.

- Read `WHAT-ITS-FOR.md` first to confirm this Emerge X style fits the project's niche before using it.
